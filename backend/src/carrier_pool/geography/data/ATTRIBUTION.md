# Texas Triangle ZIP centroid data attribution

This repository bundles a reviewed 15-ZIP Texas Triangle subset derived from the
[GeoNames Postal Code dataset](https://www.geonames.org/export/zip/), US extract,
accessed 2026-07-27. GeoNames publishes this dataset under [CC BY
3.0](https://creativecommons.org/licenses/by/3.0/).

Contains GeoNames postal-code data ([www.geonames.org](https://www.geonames.org)),
CC BY 3.0.

The subset supports only deterministic project scenarios. Coordinates are ZIP
centroids, not facility coordinates. Each row was checked against the curated
scenario location catalog on 2026-07-27; `source_accuracy` and
`data_quality_flag` remain visible in the CSV. SHA-256 of this bundled CSV:
`3fb56e9d5596a5917964fcc666b7104f2f29fafb3d1cf130f26f38f3e954fbb6`.
